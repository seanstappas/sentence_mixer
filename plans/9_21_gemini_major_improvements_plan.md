### Architecture & Implementation Plan: Sentence Mixer Enhancements

This specification provides an actionable roadmap for Antigravity to implement the four major capabilities:

1. **Automated Multi-Speaker Diarization & Classification** (Pre-processing)
2. **Hybrid Phonetic Syntax & Microphone-to-Phoneme Ingestion**
3. **Punctuation-Driven Cadence Control & Intonation Biasing (`!` / `?`)**
4. **Interactive Out-Of-Vocabulary (OOV) Learning Assistant (Default Enabled)**

---

### Module 1: Pre-processing Speaker Diarization & Classification

#### 1. Architecture Overview

When source videos feature multiple speakers, the system must separate dialogue turns without manual labeling.

* **Tier 1 (Zero Compute):** Parse embedded VTT voice tags (`<v Name>`) or script prefixes (`NAME:`).
* **Tier 2 (Neural Diarization):** Run `pyannote/speaker-diarization-3.1` on the isolated vocal stem (`vocals.wav` generated by `vocal_isolation.py`) to eliminate background music/effects interference.
* **Temporal Mapping:** Intersect diarized time intervals with MFA word boundaries, tagging each word and phone unit with its corresponding `speaker_id` in `corpus_manifest.json` and `units_index.json`.

```
                     ┌──────────────────────┐
                     │ Raw Video Input      │
                     └──────────┬───────────┘
                                │
                  vocal_isolation.py (Demucs)
                                │
                                ▼
                       vocals.wav (Clean)
                                │
            ┌───────────────────┴───────────────────┐
            ▼                                       ▼
  VTT Subtitle Cue Parser            pyannote-audio (3.1 Pipeline)
  (Check for <v Speaker> or NAME:)   (Time-boundary clustering)
            │                                       │
            └───────────────────┬───────────────────┘
                                ▼
                   Normalized Speaker Intervals
             [{"start": t0, "end": t1, "speaker_id": "SPEAKER_00"}]
                                │
                                ▼

               (Chunk tagging & MFA corpus preparation)

```

```python
from pathlib import Path
from typing import List, Dict, Any, Optional
import torch

class DiarizationPipeline:
    def __init__(self, hf_token: Optional[str] = None, device: Optional[str] = None):
        self.device = torch.device(device or ("cuda" if torch.cuda.is_available() else "cpu"))
        self.hf_token = hf_token or os.environ.get("HF_TOKEN")
        self._pipeline = None

    def _load(self):
        if self._pipeline is None:
            from pyannote.audio import Pipeline
            self._pipeline = Pipeline.from_pretrained(
                "pyannote/speaker-diarization-3.1",
                use_auth_token=self.hf_token
            ).to(self.device)

    def diarize(self, audio_path: Path) -> List[Dict[str, Any]]:
        self._load()
        diarization = self._pipeline(str(audio_path))
        intervals = []
        for turn, _, speaker in diarization.itertracks(yield_label=True):
            intervals.append({
                "start": float(turn.start),
                "end": float(turn.end),
                "speaker_id": str(speaker)
            })
        return intervals

```

### Module 2: Hybrid Phonetic Syntax & Microphone-to-Phoneme Ingestion

#### 1. Architecture Overview

Enable users to mix natural English words with explicit ARPAbet phonetic strings:

```text
"I want some {B AE1 K AH0 N} right now"

```

* **Grammar Rule:** Exactly one word unit per brace pair `{...}`. Internal phonemes must be space-delimited ARPAbet symbols.
* **Lexicon Bypass:** Bracketed expressions skip dictionary lookups in `target_graph.py` and directly form graph nodes.
* **Microphone Ingestion:** Provide an interactive tool to record speech from a mic and parse it into an ARPAbet string using an acoustic CTC phone recognizer or MFA.

#### 2. Implementation Steps

##### Step 2.1: Modify `src/target_graph.py`

* Update tokenization in `TargetGraphBuilder` to separate bracketed blocks from plain words:
```python
import re

class TargetGraphBuilder:
    def tokenize_hybrid(self, text: str) -> List[Tuple[str, bool, Optional[str]]]:
        """
        Returns tuples of (token_content, is_phonetic, trailing_punctuation).
        """
        pattern = re.compile(r'\{([^}]+)\}([.,!?;:]*)|([^\s{}]+)')
        tokens = []
        for match in pattern.finditer(text):
            bracketed, punct_b, regular = match.groups()
            if bracketed:
                clean_phones = " ".join([p.upper() for p in bracketed.split() if p.strip()])
                tokens.append((clean_phones, True, punct_b or None))
            elif regular:
                # Separate trailing punctuation from normal word
                m = re.match(r'^(.*?)([.,!?;:]*)$', regular)
                word, punct_w = m.group(1), m.group(2)
                if word:
                    tokens.append((word.lower(), False, punct_w or None))
        return tokens

```


* In `TargetGraphBuilder.build()`:
* For `is_phonetic=True`, set `pronunciations = [[p for p in token_content.split()]]`.
* For `is_phonetic=False`, call `self.lexicon.lookup(token_content)` as normal.
* Store the trailing punctuation on the created `GraphNode` for downstream cadence/prosody control.

### Module 3: Punctuation, Cadence Control & Prosody Biasing (`!` / `?`)

#### 1. Architecture Overview

Punctuation must control both temporal spacing (holding frames/silence) and acoustic unit selection (pitch contour and loudness):

* **Punctuation Pauses:** Comma (`,`) creates a natural breath gap; period/semicolon (`.`, `;`) creates a sentence stop; ellipsis (`...`) creates an extended pause.
* **Video Handling:** The video assembler freezes/holds the last frame of the preceding video cut across the gap duration.
* **Question Bias (`?`):** Rewards candidate speech spans exhibiting rising terminal pitch ($F_0$ slope $> 0$).
* **Exclamation Bias (`!`):** Rewards candidate speech spans with high RMS energy and primary lexical stress (`1`).

```
Target Sentence: "Did you hear that, Obi-Wan? Look out!"
                       │
       ┌───────────────┴───────────────┐
       ▼                               ▼
1. Cadence Parser             2. Prosodic Bias Tagger
   - "that,"   -> +180ms gap     - "Obi-Wan?" -> Bias: QUESTION
   - "cut!"    -> +350ms gap     - "out!"     -> Bias: EXCLAMATION
       │                               │
       ▼                               ▼
EditPlan.cuts         SpanSelector Viterbi
- Add EditCut(is_gap=True)   - QUESTION: lower cost for F0 slope > 0
- Freeze frame on video      - EXCLAMATION: lower cost for high RMS/stress

```

##### Step 3.3: Prosody Cost Function in `src/span_selector.py`

In `SpanSelector._compute_target_cost(unit, target_node)`:

* **Question Intonation (`?`):**
If `target_node.prosodic_bias == "question"`:
```python
# Extract f0 contour slope from unit features
f0_slope = unit.features.get("f0_slope", 0.0)
if f0_slope > 0:
    # Reward rising intonation
    cost -= min(3.0, f0_slope * 0.05)
else:
    # Penalize falling intonation at the end of a question
    cost += 2.0

```


* **Exclamation Intonation (`!`):**
If `target_node.prosodic_bias == "exclamation"`:
```python
energy = unit.features.get("rms_energy", 1.0)
has_primary_stress = "1" in getattr(unit, "phone", "")
if has_primary_stress:
    cost -= 1.5
cost -= min(2.0, (energy - 1.0) * 1.5)

```

### Module 4: Interactive OOV Word Learning System

#### 1. Architecture Overview

When `Lexicon.lookup(word)` encounters an unknown word or an ambiguous heteronym, prompt the user interactively (by default) before building the graph:

* Provide G2P predictions broken down into human-readable "sounds-like" descriptions.
* Offer choices: accept G2P, type custom phonemes, or record pronunciation via microphone.
* Automatically write approved pronunciations to `dictionaries/custom_pronunciations.txt` so the system learns permanently.
* Provide a `--non-interactive` flag to automatically fall back to raw G2P in headless/automated test runs.

#### 2. Implementation Steps

```python
def format_phoneme_breakdown(phones: List[str]) -> str:
    out = []
    for p in phones:
        base = re.sub(r"\d", "", p).upper()
        stress = " (stressed)" if "1" in p else (" (unstressed)" if "0" in p else "")
        desc = ARPABET_EXEMPLARS.get(base, base.lower())
        out.append(f"    {p:<4} -> {desc}{stress}")
    return "\n".join(out)
```

```python
def save_custom_pronunciation(self, word: str, phones: List[str], custom_path: Path):
    clean_word = word.strip().lower()
    clean_phones = " ".join([p.upper() for p in phones])
    with open(custom_path, "a", encoding="utf-8") as f:
        f.write(f"\n{clean_word}  {clean_phones}")
    # Immediately update internal in-memory lookup table
    self.entries.setdefault(clean_word, []).append(phones)
```
